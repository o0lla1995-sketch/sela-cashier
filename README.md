# سيلّا كاشير — Sela Cashier

تطبيق كاشير بسيط يعمل عبر **الشبكة المحلية (Wi-Fi)** متصلاً بتطبيق
**سيلا نقاط البيع** (أندرويد أو سطح المكتب) — للمتاجر التي يعمل فيها
أكثر من كاشير على أجهزتهم الخاصة.

## كيف يعمل؟

1. **المدير** يفعّل خادم الشبكة المحلية من شاشة «الكاشير» في تطبيق
   سيلا نقطة البيع، وينشئ حساباً (اسم مستخدم + كلمة مرور) لكل كاشير.
2. **الكاشير** يفتح هذا التطبيق على جهازه — يجد نقطة البيع تلقائياً
   على نفس الشبكة ويدخل ببياناته.
3. أول اتصال من جهاز جديد **يبقى بانتظار موافقة المدير** (اسمح/ارفض)
   من نقطة البيع — ثم يدخل تلقائياً.
4. الكاشير يبيع ويُرجع ويستبدل من منتجات المخزون **باسمه وحسابه**،
   ويراها في فواتيره وتقاريره الخاصة هنا.
5. **كل شيء يُسجَّل لحظياً في نقطة البيع**: الخزينة والديون والمخزون
   والتقارير — بلا أي مزامنة يدوية، لأن كل عملية تنفَّذ داخل تطبيق
   نقطة البيع نفسه.

## المتطلبات

- تطبيق سيلا نقطة البيع (أندرويد v58+ أو سطح المكتب v63+) مفتوحاً
  ومفعَّل الخادم فيه.
- الجهازان على **نفس شبكة Wi-Fi**.
- عند أول تشغيل على ويندوز اسمح للتطبيق عبر جدار الحماية.

## البناء

```bash
npm install
cd android && ./gradlew assembleRelease
# APK: android/app/build/outputs/apk/release/app-release.apk
```

أو من Releases — `SelaCashier-v*.apk`.

## البروتوكول

- اكتشاف نقاط البيع: بث UDP على المنفذ **8951** (`SELA_POS_DISCOVER_v1`).
- الاتصال: HTTP JSON على المنفذ **8950** برمز جلسة Bearer.
- الأسعار والخصومات تُحسم دائماً من قاعدة نقطة البيع — تطبيق الكاشير
  لا يُصدَّق على أي سعر.
